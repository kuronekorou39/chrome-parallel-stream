# Parallel Stream

Twitch / YouTube / mellow-fan(旧 OPENREC) / Kick の配信を、1画面に並べて同時に見るための Chrome 拡張機能です。

---

## 画面

サイトを選ぶか URL を貼って、枠を1つずつ足していきます。

| | |
| --- | --- |
| <img src="docs/images/01-empty.jpg" alt="枠がまだ無い状態。左に ≡ メニュー、右下に「枠を追加」ダイアログ"> | <img src="docs/images/02-one.jpg" alt="1枠だけ表示した状態。映像の上をコメントが流れている"> |
| **枠を追加** — `≡` メニューから、サイトのボタンか URL で | **1枠** — 映像・チャット・弾幕(コメントを映像の上に流す) |
| <img src="docs/images/03-four.jpg" alt="4枠を並べた状態。右上に枠一覧と配置パネル"> | <img src="docs/images/04-many.jpg" alt="7枠を並べた状態"> |
| **4枠** — 枠一覧で音量、配置パネルで整列 | **さらに追加** — 大きさと位置は枠ごとに自由 |

---

## できること

- 配信をいくつでも並べて、大きさと位置を自由に決める
- 枠ごとに音量を変える(全部まとめても)
- コメントを映像の上に流す(弾幕)
- 並べ方に名前を付けて保存し、あとで呼び出す
- スマホでは縦に積んで見る

---

## インストール

**[UI ページ](https://kuronekorou39.github.io/chrome-parallel-stream/multiview.html)を開くだけでは動きません。拡張機能が必須です。**

1. このリポジトリをクローンする
2. Chrome で `chrome://extensions` を開き、「デベロッパーモード」を ON
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるディレクトリを選ぶ
4. ツールバーのアイコン → 「マルチビューを開く」

---

## インストールする前に

配信サイトを並べるために、この拡張はブラウザに踏み込んだ変更をします。
なかでも **Cookie の変更はブラウザ全体に残ります**(設定で元に戻せます)。

何をどこまで変えるかは **[ブラウザに与える影響](docs/browser-impact.md)** に書いてあります。
**読んでから入れてください。**
